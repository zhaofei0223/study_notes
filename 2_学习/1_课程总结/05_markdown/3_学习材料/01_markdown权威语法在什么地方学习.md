Markdown 权威语法学习，首选官方文档和中文社区教程，可从以下渠道入手：

- 官方中文教程：[Markdown 官方教程](https://markdown.com.cn/basic-syntax/) 中文版，系统讲解基本语法，适合新手入门。
- Markdown 中文网：[Markdown 中文网](https://markdown.p2hp.com/) 免费开源参考指南，含基本语法、扩展语法和速查表，可随时查阅。
- MARKDOWN 中文：[MARKDOWN 中文](https://www.markdown.cn/) 免费开源参考指南，内容简洁，花5分钟即可了解整体语法框架。

📖 权威规范与进阶学习
- CommonMark 规范：Markdown 最权威的语法标准，各平台解析器均基于此，深入理解语法细节可参考。
- GFM 扩展语法：GitHub 主导的扩展标准，支持表格、任务列表、删除线等常用功能，实际使用中广泛支持。

🛠️ 交互式练习平台
- Markdown Tutorial：[Markdown Tutorial](https://www.markdowntutorial.com/) 交互式教程，边学边练，实时查看效果。
- Dillinger：[Dillinger](https://dillinger.io/) 在线编辑器，支持实时预览和导出，适合动手实践。
- StackEdit：[StackEdit](https://stackedit.io/) 功能强大，支持实时预览和云存储集成。

> 注意：不同编辑器对扩展语法支持程度不一，基础语法通用，但表格、数学公式等高级功能需确认所用工具是否支持。
