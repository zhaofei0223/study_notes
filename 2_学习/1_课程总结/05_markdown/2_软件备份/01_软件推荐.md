# 软件推荐
因为 Typora 是收费软件，在办公场地可能不能使用，‌MarkText、mdput、Obsidian、VS Code（配插件）、uTools（装Markdown插件）‌，它们都能接替Typora的核心写作场景，而且大多免费开源。‌‌

## marktext
**简介**

MarkText号称下一代Markdown编辑器，一个简单而优雅的开源 Markdown 编辑器，专注于速度和可用性。适用于 Linux、macOS 和 Windows，支持表格、流程图、甘特图、数学公式、代码高亮、图床等功能，还拥有多种主题、拼写检查等功能，基本能替代 Typora ，另外就是非在线保存，重要文件保存在自己电脑，可以不受别人的约束。MarkText 是 MIT 许可的开源项目，最新版本始终可以从 GitHub 发布页面免费下载。

**特征**

实时预览 (WYSIWYG) 和简洁明了的界面，让您获得无干扰的写作体验。

支持CommonMark Spec、GitHub Flavored Markdown Spec和选择性支持Pandoc markdown。

Markdown 扩展，例如数学表达式 (KaTeX)、前端和表情符号。

支持段落和内联样式快捷方式，以提高您的写作效率。

输出HTML和PDF文件。

各种主题：Cadmium Light，Material Dark等。

多种编辑模式：源代码模式、打字机模式、焦点模式。

直接从剪贴板粘贴图像。
