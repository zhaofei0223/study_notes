iperf3 是网络性能测试工具，用于测量 TCP/UDP 带宽、吞吐量和丢包率，采用客户端 - 服务器模式运行。
常用参数详解

- -s：服务端模式，监听连接。
- -c 服务器 IP：客户端模式，连接指定服务器。
- -p 端口：指定端口，默认 5201。
- -t 秒数：测试时长，默认 10 秒。
- -i 秒数：报告间隔时间。
- -u：使用 UDP 协议，默认 TCP。
- -b 带宽：限制测试带宽，UDP 默认 1Mbit/s。
- -P 数量：并行数据流数量。
- -R：反向测试，服务端发送数据。
- -A CPU 编号：绑定指定 CPU。
典型测试场景

1. TCP 带宽测试：`iperf3 -c 192.168.1.1 -t 60 -i 1`
2. UDP 带宽测试：`iperf3 -c 192.168.1.1 -u -b 1000M -t 60`
3. 并行多流测试：`iperf3 -c 192.168.1.1 -P 4`
4. 反向下载测试：`iperf3 -c 192.168.1.1 -R`
结果解读

- Transfer：传输总数据量。
- Bandwidth/Bitrate：测试带宽。
- Retr：TCP 重传包数。
- Jitter：UDP 抖动。
- Lost/Total：UDP 丢包率。

服务端启动命令：`iperf3 -s -p 5201`，客户端连接后双方均显示测试结果。

---

基础命令与常用参数
| 功能  | 服务端命令  | 客户端命令  |
|---|---|---|
| 启动服务  | `iperf3 -s`  | -  |
| 基础测试  | -  | `iperf3 -c <服务器 IP>`  |
| 指定端口  | `iperf3 -s -p 5202`  | `iperf3 -c <IP> -p 5202`  |
| UDP 测试  | -  | `iperf3 -c <IP> -u -b 1G`  |
| 反向测试  | -  | `iperf3 -c <IP> -R`  |
| 多线程  | -  | `iperf3 -c <IP> -P 4`  |
| 指定时长  | -  | `iperf3 -c <IP> -t 30`  |

关键参数说明：`-s` 服务端模式，`-c` 客户端模式，`-u` 使用 UDP，`-b` 设置带宽限制，`-P` 并行连接数，`-t` 测试时长（秒），`-R` 反向传输 。默认监听端口为5201，默认测试时长10 秒，UDP 默认带宽限制1 Mbit/sec 。
实战测试示例

场景 1：基础带宽测试
```
服务端：iperf3 -s
客户端：iperf3 -c 192.168.1.100 -t 30 -P 4
```

输出显示每秒带宽、传输总量、重传次数等 。
场景 2：UDP 丢包测试
```
客户端：iperf3 -c 192.168.1.100 -u -b 1G -t 30
```

用于评估 VoIP、视频等实时应用场景 。
场景 3：双向带宽测试
```
客户端：iperf3 -c 192.168.1.100 -d
```

同时测量上传和下载带宽 。

常见问题：测速结果偏低可能是防火墙未放行 5201 端口，需在 Windows 防火墙或 Linux firewalld 中开放该端口 。UDP 模式下 `-P` 参数在某些系统可能不兼容，建议服务端使用 Linux 系统 。
